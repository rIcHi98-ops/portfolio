RICHARD HEIM — FREELANCER-WEBSITE
==================================

Stand: 22. September 2026

Diese statische Portfolio- und Dienstleistungswebsite präsentiert das Angebot
von Richard Heim in den Bereichen Webentwicklung, Webdesign, CMS-Lösungen,
Hosting-Begleitung und individuelle KI-Automatisierungen.


LOKAL ANSEHEN
1. Den Ordner „richard-heim-freelance“ öffnen.
2. Die Datei „index.html“ per Doppelklick öffnen.

Die Website funktioniert direkt im Browser. Eine Installation, ein lokaler
Server, ein API-Key oder eine Internetverbindung sind nicht erforderlich.


STATISCH VERÖFFENTLICHEN
Den vollständigen Inhalt dieses Ordners in das Hauptverzeichnis des Webspaces
oder in das für GitHub Pages verwendete Repository hochladen.

Wichtig:
- „index.html“ muss im Hauptverzeichnis liegen.
- „impressum.html“ muss neben „index.html“ liegen.
- Der Ordner „assets“ muss vollständig hochgeladen werden.
- „favicon.ico“ und „.nojekyll“ gehören ebenfalls ins Hauptverzeichnis.
- Die Datei „.nojekyll“ verhindert bei GitHub Pages eine unnötige Verarbeitung
  durch Jekyll und sorgt für eine unveränderte statische Auslieferung.
- Bei GitHub Pages sollte unter „Settings → Pages“ die Option „Enforce HTTPS“
  aktiviert werden.


AKTUELLER INHALT
- Persönlicher Hero-Bereich mit Portrait und direkter Projektanfrage
- Sieben klar abgegrenzte Leistungen mit individueller Webentwicklung als
  Schwerpunkt und CMS-Websites als ergänzender Option

  und optionaler laufender Betreuung
- Interaktives Workflow Lab mit vier beispielhaften KI-Automatisierungen
- Darstellung des Projektablaufs von Briefing bis Launch und Betreuung
- Persönliches Profil, Arbeitsweise und Werkzeugkasten
- Beispiele für mögliche Projektformate
- Kontaktformular, das eine vorbereitete E-Mail im lokalen E-Mail-Programm öffnet
- Vollständige deutsche und englische Sprachfassung
- Automatischer Sprachhinweis bei englischer Browsersprache
- Manuelle Sprachumschaltung auf Startseite und Impressum
- Responsive Navigation, Back-to-top-Button und dezente Interaktionen
- Eigenständige Impressumsseite mit E-Mail-Adresse als Kontaktmöglichkeit

TECHNISCHE GRUNDLAGE
- Reines HTML, CSS und JavaScript
- Keine Datenbank und kein serverseitiges Backend
- Keine Frameworks, externen Bibliotheken oder externen Schriftarten
- Keine Cookies, Analysewerkzeuge oder Werbetracker
- Keine extern nachgeladenen Website-Bestandteile
- Die gewählte Sprache wird ausschließlich lokal im Browser gespeichert
- Das Kontaktformular überträgt keine Daten an einen Website-Server, sondern
  öffnet über einen mailto-Link das E-Mail-Programm der besuchenden Person
- Relative Dateipfade für GitHub Pages, klassische Webspaces und lokale Nutzung
- Responsives Layout für Desktop, Tablet und Smartphone
- Bedienung per Tastatur sowie Unterstützung reduzierter Bewegungseffekte
